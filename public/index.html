Reset Password

Permintaan reset dikirim ke antrean RabbitMQ, lalu dikirim sebagai email oleh proses terpisah. Jawaban API selalu sama, terdaftar maupun tidak.

1. Minta Tautan Reset
POST /auth/forgot-password · dibatasi 3 kali per jam
2. Tukar Token dengan Password Baru
POST /auth/reset-password · minimal 12 karakter · token sekali pakai
Yang Terjadi di Balik Layar
1 · Token
32 byte acak, yang disimpan hanya hash-nya
2 · Redis
Berlaku 15 menit, lalu hangus sendiri
3 · RabbitMQ
Perintah kirim dititipkan, API langsung menjawab
4 · Worker
Proses terpisah mengirim email lewat SMTP
